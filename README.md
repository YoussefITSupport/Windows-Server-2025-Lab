### Windows Server 2025 – Active Directory Lab
## 1. Project Overview
Built a Windows Server 2025 lab 
environment using VirtualBox to practice
basic IT infrastructure administration
and Active Directory management.
## 2. Lab Environment
- Windows Server 2025
- Windows 10 Pro Client
- Oracle VirtualBox
- Domain Name: test.local
- Server IP: 192.168.10.10
## 3. Technologies Used
- Active Directory Domain Services (AD DS)
- DNS
- User and Group Management
- Organizational Units (OUs)
- Shared Folders
- NTFS Permissions
- Domain Join
## 4. Project Implementation
- Installed and configured Active Directory Domain Services.
- Created Organizational Units for different departments.
- Created domain users and security groups.
- Joined a Windows 10 Pro client to the domain.
- Configured shared departmental folders.
- Assigned Modify permissions to the IT security group.
- Tested folder access and permission restrictions.
## 5. Permission Testing
Verified that authorized users could access 
their assigned folders while unauthorized users were denied access.
## 6. Screenshots
Screenshots demonstrate the Active Directory configuration, domain join, user and group management, folder permissions, and access testing.
## 7. Learning Outcomes
Gained practical experience in Windows Server administration, Active Directory, domain management, user permissions, and basic troubleshooting.
